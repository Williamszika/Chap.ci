UN SEUL CHANGEMENT : ON NE DEMANDE PLUS LE CODE E-MAIL AVANT D'AVOIR ÉCRIT
SON ANNONCE.

Quelqu'un qui venait de s'inscrire et cliquait « Publier ma première annonce »
tombait sur un champ de code à six chiffres — SANS AVOIR TAPÉ UN MOT de son
annonce. Le mur arrive maintenant au moment d'appuyer sur « Publier ».

C'est 🤝 Le Concierge qui l'a relevé, et son argument est imparable : la même
page avait déjà réglé ce problème pour le mur du COMPTE le 29 août, avec son
chiffre écrit dans le code — « cinq personnes sur huit s'arrêtaient au mur,
contre une sur huit dans le formulaire ». Le mur e-mail n'avait jamais reçu ce
traitement. Votre application Android, elle, faisait déjà bien les choses : le
site était en retard sur sa propre application.

RIEN N'EST ASSOUPLI. Aucune annonce ne part sans adresse confirmée : le serveur
le refuse, et il le refusait déjà avant ce zip (vérifié par 🛡️ Le Gardien —
« le changement est purement une réorganisation de l'écran, le serveur exige
toujours l'e-mail confirmé »). On a déplacé le moment, pas la règle.

⚠️⚠️ ET RECHARGEZ DEUX FOIS — C'EST NOUVEAU, ET ÇA VOUS A DÉJÀ PIÉGÉ
---------------------------------------------------------------------
Le 13 septembre, vous ne voyiez pas un onglet d'administration pourtant
déployé : empreintes vertes, fichier servi, et votre navigateur affichait
l'ancien. Chap.ci est une application installable (PWA) : LE PREMIER
RECHARGEMENT INSTALLE LA NOUVELLE VERSION, LE SECOND LA SERT.

Donc, après extraction :
  1. Fermez TOUS les onglets chap.ci
  2. Rouvrez chap.ci
  3. Rechargez une seconde fois (Cmd+R)

La preuve en trente secondes si un doute subsiste : ouvrez chap.ci dans une
fenêtre de navigation privée (Cmd+Maj+N). Une fenêtre privée n'a pas de cache
d'application. Si la nouveauté y est, tout est en ordre.


LA VÉRIFICATION QUI SE VOIT À L'ŒIL NU
--------------------------------------
Avec un compte dont l'adresse n'est PAS confirmée, ouvrez chap.ci -> Publier.

  AVANT : le champ de code à six chiffres, tout de suite.
  APRÈS : le formulaire d'annonce. Le code n'est demandé qu'en appuyant
          sur « Publier », et votre annonce est gardée pendant ce temps.

Si vous n'avez pas de compte non confirmé sous la main, ce n'est pas grave :
l'empreinte suffit.
